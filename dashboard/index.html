Methodology & data-quality notes

  • Source: data/raw/smart_logistics_dataset.csv — 1,000 shipment records across 10 trucks, Jan 01 – Dec 30, 2024. Every figure on this dashboard is recomputed from that file.
  • Target leakage (corrected): Shipment_Status = "Delayed" is delayed 100% of the time (350/350), and Logistics_Delay_Reason only exists when a delay occurred. Including either as a predictor lets a model trivially reach ~100% accuracy — so both were excluded from the model.
  • Leakage-free result: the honest benchmark is Random Forest at 78.0% accuracy / 0.794 AUC, not the ~84% figure in the original README (which predates the current dataset and included leaky features).
  • Data nuance: 263 shipments (26%) have no recorded delay reason (stored as the literal string "None"); these are shown as "No recorded reason", not dropped.
  • Traffic signal: Traffic_Status = "Heavy" co-occurs with delay 100% of the time in this dataset — a strong (near-deterministic) signal that dominates feature importance.
